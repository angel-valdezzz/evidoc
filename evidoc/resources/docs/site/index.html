    Manual tecnico de usuario¶

    Evidoc transforma la ejecucion de pruebas en evidencia estructurada y en reportes que se pueden leer, compartir y auditar.

    Este manual esta orientado a usuarios finales tecnicos: testers funcionales, testers de automatizacion, desarrolladores y cualquier perfil que necesite registrar pasos, conservar artefactos, entender el resultado almacenado en disco y convertirlo en reportes PDF o DOCX con una narrativa clara.

    Empezar instalacion Ir a las guias tecnicas
    Que resuelve Evidoc

    Evidoc ordena un problema que normalmente termina disperso entre screenshots sueltos, notas manuales y logs sin contexto:

    1. Capturar evidencia estructurada durante la ejecucion de una prueba.
    2. Relacionar esa evidencia con pasos y mensajes para que la historia de la ejecucion sea entendible.
    3. Convertir el resultado en un entregable legible por QA, desarrollo y auditable por terceros.

    Esa separacion permite cambiar la forma de ejecucion sin perder consistencia en la salida ni en la trazabilidad del resultado.

      Revisa el panorama funcional para entender conceptos, perfiles y el modelo operativo completo.

    • Levantar el flujo minimo

      Sigue primeros pasos si necesitas instalar, configurar y producir tu primer reporte rapido.

    • Elegir interfaz

      La seccion guias tecnicas cubre CLI, TUI, Python API y Robot Framework con ejemplos completos.

    • Consultar la referencia

      Usa referencia para revisar esquemas, comandos, keywords, estados y convenciones exactas.

    Rutas rapidas por perfil¶

    Empieza en Recorrido guiado, luego pasa a TUI y termina con Reportes y salidas.

    Prioriza Robot Framework, CLI y Estructura de resultados.

    Empieza por Modelo operativo, sigue con Python API y valida contratos en Referencia.

    Ve primero a Que es Evidoc, despues Reportes y salidas y cierra con Buenas practicas.

    Capacidades cubiertas por este manual¶

    • Captura de pasos, logs, screenshots y archivos adjuntos.
    • Generacion de reportes por corrida completa o por prueba individual.
    • Uso desde CLI, interfaz TUI, API Python y Robot Framework.
    • Estructura exacta del resultado almacenado en disco.
    • Configuracion por archivo evidoc.json o evidoc.toml.
    • Limitaciones operativas, convenciones y troubleshooting.
