# Interfaz de consola

Abre la interfaz interactiva con:

```bash
poetry run evidoc tui
```

En la pestaña de operación, indica la carpeta de metadatos, la carpeta de salida y el formato. Ejecuta la generación para crear un documento por caso y el manifiesto de carga. Puedes escribir las rutas o seleccionarlas desde el explorador de carpetas de Windows.

| Atajo | Acción |
| --- | --- |
| `F1` | Abre la bienvenida. |
| `F2` | Abre la operación. |
| `Ctrl+S` | Selecciona la carpeta de metadatos. |
| `Ctrl+O` | Selecciona la carpeta de salida. |
| `Ctrl+G` | Genera documentos. |

Para filtrar casos, asignar defectos o combinar varias ejecuciones, utiliza los [comandos de consola](cli.md). La interfaz informa las rutas generadas o avisa cuando no encuentra resultados.
